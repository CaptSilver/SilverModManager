# SilverModManager developer notes

These notes describe how the code works. Most of them were written for the upstream Nexus Mods
App and still describe the shared code, including the `NexusMods.*` project names, which the fork
keeps. Where a note mentions Windows, macOS, Discord or the upstream release process, it
describes upstream and not this fork.

* [Developer docs](./developers/index.md): design notes, decision records and coding guidelines.
* [`CONTRIBUTING.md`](../CONTRIBUTING.md): building, testing and packaging on Linux.
* [`NOTICE`](../NOTICE): what the fork is based on and how it is licensed.
