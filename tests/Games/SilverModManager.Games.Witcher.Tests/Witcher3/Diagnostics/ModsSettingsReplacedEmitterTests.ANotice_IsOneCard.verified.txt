[Id] SilverModManager.Games.Witcher.Witcher3: 1
[Title] mods.settings was replaced
[Summary] The mods.settings in Documents/The Witcher 3 was replaced by the one built from your Load Order, because the file on disk differed from your Load Order (in a different order: modA, modB)
[Details]
The Witcher 3 reads **mods.settings** to decide which Mods folders load and in what order. The app writes it from your Load Order on every Apply, so the copy in Documents/The Witcher 3 was replaced, because the file on disk differed from your Load Order (in a different order: modA, modB).

To keep a different order or switch, set it on the Load Order page.
